================================================================
BiliNote 产出格式基准 (来自 GitHub README + 竞品调研)
================================================================

给用户作为 "目标产物" 的参照 —— 等我们跑通后, 对比我们的产出是否覆盖了这些点.

────────────────────────────────────────────────────────────────
1. 输入 (BiliNote 支持的)
────────────────────────────────────────────────────────────────

  • B 站 URL/BV 号
  • YouTube URL
  • 抖音 URL
  • 快手 URL
  • 本地 mp4 (拖拽上传)
  • 浏览器插件: 在 B 站原页面直接生成笔记

────────────────────────────────────────────────────────────────
2. 输出 (按类型分)
────────────────────────────────────────────────────────────────

  A. Markdown 笔记 (.md)
     ├── 视频元信息 (标题/UP主/时长/简介)
     ├── 自动章节大纲 (按内容分章节, 每章 200-500 字)
     ├── 关键观点摘要 (5-10 条)
     ├── 关键时间戳 (可点击跳转)
     └── 引用截图 (从视频里截, 嵌在对应位置)

  B. 时间戳索引 (.json / .md 链接)
     ├── 02:15 课程介绍
     ├── 05:30 第一个知识点
     ├── 12:45 ...
     └── 点击跳转 B 站原视频 (URL + ?t=<sec>)

  C. 思维导图 (markmap 单文件 HTML)
     ├── 一键渲染
     ├── 节点可点击跳转
     └── 单文件可分享

  D. 自动截图 (ZIP)
     ├── 每个章节的代表性截图 1-3 张
     └── 文件名带时间戳

  E. AI 问答 (RAG)
     ├── 跑完笔记后, 可以问 "讲了什么?" "X 是什么?"
     └── 基于笔记+字幕检索

────────────────────────────────────────────────────────────────
3. 转写引擎 (用户可选)
────────────────────────────────────────────────────────────────

  • Fast-Whisper (本地, CPU/GPU 都行, 推荐 tiny/base)
  • MLX-Whisper (Apple Silicon 加速)
  • Groq 在线 (免费额度, 快)
  • 必剪 (字节官方, 限制多)
  • 快手 ASR
  • B 站官方字幕 (需登录, 优先用这个, 失败才走 ASR)

────────────────────────────────────────────────────────────────
4. 视觉模型 (用户可选)
────────────────────────────────────────────────────────────────

  • GPT-4o (云端, 贵但准)
  • Claude 3.5 Sonnet (云端, 推荐)
  • Gemini 2.0 Flash (云端, 便宜)
  • 本地 vLLM + Qwen2-VL/InternVL2 (需 GPU)
  • 不开视觉 (只用字幕生成笔记)

────────────────────────────────────────────────────────────────
5. 部署形态
────────────────────────────────────────────────────────────────

  • Web (浏览器开 http://localhost:3001)
  • Windows .msi 安装包
  • macOS .dmg 安装包
  • Chrome 浏览器插件 (在 B 站原页面直接生成)
  • Docker (一键)

────────────────────────────────────────────────────────────────
6. 我们要赶超的最低标准 (MVP)
────────────────────────────────────────────────────────────────

  ✅ 输入: B 站 BV 号 (有 cookies 登录态)
  ✅ 输出: Markdown 大纲 + 时间戳可点击跳转 + 自动截图 1-3 张/章
  ✅ 转写: B 站官方字幕优先, 失败走本地 Whisper
  ✅ 思维导图: markmap 单 HTML
  ❌ AI 问答: 不在 MVP 范围
  ❌ 浏览器插件: 不在 MVP 范围

  评估 MVP 通过的标准:
    1. 用户给一个 BV 号
    2. 30 分钟内拿到 4 个文件:
       - <video>.md (笔记)
       - <video>_shots/ (截图)
       - <video>.html (markmap 思维导图)
       - <video>_timestamps.json (时间戳索引)
    3. 笔记内容跟视频实际讲的对得上 (用户抽查 1-2 个章节)
