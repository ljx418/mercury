05 User journey

从默认兜底到生产资格

普通用户只处理安装和选择；两名 reviewer 只处理高风险质量判断。

1

首次启动

Tiny 随 Runtime ready；无需 GPU；界面明确仅为兜底。

2

安装候选

用户点击 Paraformer；查看下载、资源、校验和失败恢复。

3

真实资格

自动生成相同三样本输出；两名 reviewer 独立比较，不听写。

4

明确结果

只有 44/48、每样本15/16、critical=0、neither=0 才显示已资格化。
