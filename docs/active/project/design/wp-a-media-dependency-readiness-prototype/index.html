交互约束

一次明确操作

用户只在依赖缺失时点击一次“修复本机依赖”。下载、校验、自检与启用连续完成。

日常零打扰

依赖 ready 后，分析按钮直接进入字幕或受控下载路径，不再要求处理工具安装。

失败可恢复

网络、空间、摘要、权限、自检和系统工具缺失分别给出下一步，不显示笼统 Runtime offline。

首次配置路线

1. Runtime 在线复用现有本机伴侣安全会话。
2. 读取依赖状态Settings 一次读取工具与 ASR 聚合状态。
3. 显式修复仅缺失时显示操作，固定来源下载 yt-dlp。
4. 校验与自检字节、SHA-256、可执行性和最小命令自检。
5. 发布 ready媒体任务获得不可变 verified generation。

日常分析路线

打开 B站视频页面身份与授权保持不变。
优先字幕公开或凭据字幕成功即不下载媒体。
依赖快照下载路线只读取 ready generation。
下载 + SenseVoice任务期媒体进入私有沙箱，完成后清理。
仍失败则 blocked不静默启动 tabCapture；本地文件导入属于 WP-B。
