## 1. 结论

`t02-r2-raw-production-input-20260912T001213` 在真实 Chrome 启动前被
`frontend_full_tests` 前置门槛拒绝。该 run 没有 seal、不得补写、不得与后续 run

第二次全量尝试 `t02-r2-raw-production-input-20260912T002200` 在同一门槛得到相同

第三次全量尝试 `t02-r2-raw-production-input-20260912T003200` 已通过前述前端测试，
但 T01 回归在启动浏览器时终止。新增诊断证明隔离工作树默认寻找其自身 `.tmp` 下的
Windows Chrome；该路径不存在后回退到 Linux Playwright Chromium，而当前 WSL 环境缺少
`libnspr4.so`。这属于隔离运行配置错误，不是产品行为失败。该 run 同样没有 seal，已作废。

第四次全量尝试 `t02-r2-raw-production-input-20260912T003900` 显式选择 Windows Chrome，

同时 Windows sandbox 无法稳定访问 UNC profile，network service 终止，WSL 侧最终得到
`Chrome did not expose CDP`。该 run 同样没有 seal，已清理作废。

## 2. 原始失败事实

失败诊断位于：

```text
runs/t02-r2-raw-production-input-20260912T001213/raw/collection-diagnostic.json
```

诊断记录 `frontend_full_tests failed: exit=1`。失败 run 仅包含诊断和清理清单，
没有 `raw-run.json`、artifact index 或 seal，因而不满足任何正向验收输入条件。

清理清单位于：

```text
runs/t02-r2-raw-production-input-20260912T001213/cleanup-manifest.json
```

其中 browser、Runtime、fixture server、profile 四项均已完成清理。

## 3. 独立复核

在相同隔离工作树和相同提交上独立重跑：

```text
cd apps/chrome-extension
pnpm test
```

在相同提交上分别通过直接执行和最小 Node `spawnSync` 包装执行；结果均为：

```text
Test Files  22 passed (22)
Tests       169 passed (169)
exitCode    0
```

这只证明两次聚合失败未能稳定复现，不证明 T02.1 已通过，也不能替代新 run 内记录的
`frontend_full_tests` command evidence。由于首次 runner 在抛错前未持久化该命令的
stdout/stderr，本轮不对两次失败作超出证据的根因声明。

为关闭诊断盲区，collector runner 仅增加失败 stdout/stderr 尾部记录；行为仍为首个
失败立即终止，不加入自动重试、不降低并发、不跳过测试。该诊断改动必须先通过语法和
collector 单元测试，之后才允许创建新的 run。

## 4. 重试决定

允许使用新的独立 run ID 从零重试，理由如下：

1. 失败发生在采集前，没有污染可接受 raw evidence。
2. 清理清单通过，未留下浏览器、Runtime 或临时 profile。
3. 相同提交上的全量前端测试随后完整通过。
4. 不修改产品代码、不降低阈值、不跳过任何 prerequisite。
5. 后续 run 显式传入主机上已存在的 Windows Chrome for Testing 可执行文件；该私有绝对
   路径不得进入公开证据。
6. Windows Chrome 使用的 extension build 和 browser profile 必须位于 `/mnt/c` 映射路径，
   不得使用 Linux `/tmp` 转换出的 UNC 路径。

第五次 run 触发产品可访问性硬门槛后，不再允许以相同代码重试。后续只有在独立的
T02.1a 修复计划获批并完成产品色彩对比修复后，才允许创建新的完整 run。

重试必须满足：

```text
新 run 独立执行全部 prerequisite
新 run 独立创建 build/profile/runtime/db/raw/seal
NAVIA_T02_SKIP_PREREQUISITES 不得启用
不得引用或合并本失败 run
不得引用或合并旧 accepted run t02-r2-raw-20260911T143100
```
