## 2. 用户场景检视

```text
用户从 Side Panel 点击查看来源
-> Workspace Source Detail 打开
-> Source ID / Operation ID / 状态 / Revision 标签可读
-> Evidence 说明文字可读
-> 键盘打开并关闭 Trace 后焦点返回
```

人工或截图核查必须确认：文字没有因颜色修改失去层级、没有隐藏、重叠或溢出。该核查只支持
本次颜色修复，不替代 PX-5 后续完整人工体验签署。

## 3. 防假绿规则

- 只允许新 run 的 Axe 结果作为通过证据。
- 必须扫描 Side Panel 与 Workspace；不能只扫描无问题页面。
- Axe artifact 必须与 command result、artifact index 和 seal 关联。
- 不接受禁用 color-contrast、排除目标节点或降低 impact。
- 新 run 若失败即作废；不能从历史 run 补齐缺项。

## 4. PRD 出门声明

全部门槛通过且独立复审前，只能声明：

```text
T02.1 accessibility repair and production-input candidate completed locally;
pending independent audit.
```

不得声明 PX-5、V2、完整外脑、RAG 或自动维护完成。
