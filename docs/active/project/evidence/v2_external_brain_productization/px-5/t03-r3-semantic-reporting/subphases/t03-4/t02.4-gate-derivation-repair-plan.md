# T03-4 T02.4 Gate 派生修复计划

## 问题

T02.4 正基线已通过 63 条规则和 42 个 production mutation；旧 T02.3 也会触发 `PX_RULE_RUNTIME_OFFLINE_AUTHORITY_VIOLATION`。但 `ProductionValidation.gateResults.G5` 只读取 Status Schema 结果，没有纳入 Runtime offline authority，导致“规则失败、G5 仍 passed”的内部矛盾。

## 最小修复

1. 在 `v2PxProductionValidation.mjs` 冻结 63 条 RuleId 到 G1-G7 的一对一映射。
2. Gate 只从 `ruleResults` 重算：映射内任一 failed 则 Gate failed；否则任一 pending 则 pending；否则 passed。
3. 初始化时拒绝未映射、重复映射或非 G1-G7 的映射，不新增或修改 RuleId、FailureCode、Schema 或 G1-G7 分母。
4. T02.4 必须继续得到 G1-G6 passed、G7 pending；T02.3 必须得到 G5 failed；T02.2 必须继续得到 G5 failed。
