## 9. 必答问题 5：原 T03 raw InvocationRecord 是否仍保持不可变；T04.1 只派生 `resolved-invocation-record.json`

- 不可变性断言：派生前后原始 `replay/output/invocation-record.json` SHA-256 必须相等；`compareInvocationRecord` 只允许忽略 `/recordedAt`，不得把 `artifactRoot` 加入 normalization allowlist（`05-t04.1-development-plan.md` §1 + `06-t04.1-acceptance-plan.md` §2 双重约束）。

结论：原 T03 raw InvocationRecord 保持不可变；T04.1 只派生 `resolved-invocation-record.json`，路径 / root / 算法三重约束。**OK**。
