验收准备

使用真实 Runtime、真实扩展和真实可丢弃来源。不要把机器截图或 review prototype 当作人工操作替代品。

环境与入口

  1. H01 必须启动真实知识服务模式；普通 uvicorn 默认仍是 Mock，不能用于 H01。./scripts/h01_real_data_service.sh start./scripts/h01_real_data_service.sh status
  2. 在 Chrome 扩展管理页加载已解压目录。apps/chrome-extension/chrome-mv3-unpacked
  3. 刷新扩展后打开指定真实页面。https://www.bilibili.com/video/BV1ZpYd66ELPH01 开始前必须看到 adapterStatus=ready、dataServiceStatus=connected，不得出现 Mock 或 unchecked。
  4. 使用可见 Chrome 操作；不要以 headless 录像、DOM 注入或脚本点击替代 H01–H07。
  5. 当前 real adapter 只覆盖持久化、build 和 trace。H02–H07 所需 Query/Graph/Forget 尚未全量接入；不得因 H01 解阻而连续签署 PX-6 总通过。

证据与停止规则

  1. 每个 Gate 至少保存一条实际证据，推荐 PNG 截图、JSON 观察记录或 Markdown 审查笔记。
  2. 证据必须属于本次 PX-6 run；不跨 run 拼接，不修改 T04.1 或机器候选原始字节。
  3. 任何预期不满足，立即将该 Gate 标记为失败并写明 blocker；不要继续填写成功声明。
  4. 文件选择器只计算本地文件 SHA-256 与大小，不上传文件。页面草稿只存文字和哈希。
