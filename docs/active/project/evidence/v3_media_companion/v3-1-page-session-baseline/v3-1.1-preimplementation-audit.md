## 2. 当前代码事实

- `wxt.config.ts`、content entry 与 WAR 仍含 `<all_urls>`，是本子阶段必须修复的已知差异，不是通过状态。
- background 当前在 tab updated/activated 时尝试全站注入；路线 A 要求删除该隐式路径，仅保留 action/command。
- `contentBridge.ts` 当前把消息 bridge 与 in-page launcher 绑定；必须拆分 `portal_auto` 与 `bridge_only`，否则普通页 action 会产生双 UI。
- 当前没有 `media_companion` 模块、portal adapter registry 或产品媒体消息；不会把 V3-1P probe 当实现。
