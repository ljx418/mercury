# V3-1.1 字幕能力双源判定修复

日期：2026-09-17  
状态：`IMPLEMENTED; REAL-CHROME REVALIDATION REQUIRED`

## 1. 失败事实

`v3-1.1-media-page-20260917T075000Z` 在首个真实字幕样本停止。匿名播放器 API 返回空字幕列表，原实现因此报告 `unavailable`。V3-1P 已封存的同页证据同时包含具体播放器语言项和 HTML 中的字幕制作者事实，但产品 adapter 尚未实现该双源回退。

该失败 run 不封存、不计入通过分母，也不与后续 run 拼接。

## 2. 冻结语义

`transcriptAvailability` 在 V3-1.1 表示页面声明的字幕能力，不表示字幕正文已下载。判定顺序固定为：

1. 页面出现充电、会员、登录或地区限制事实时为 `restricted`；
2. 播放器 API / bootstrap 返回至少一个字幕项时为 `available`；
3. 匿名 API 为空时，只有“具体语言项”与“字幕制作者”两个独立页面事实同时存在，才为 `available`；
4. API 明确返回空列表且双源页面事实不成立时为 `unavailable`；
5. 无法形成上述事实时为 `unknown`。

标题、简介、通用字幕按钮、单独的语言下拉项均不得升级为 `available`。V3-2 仍须实际获取并校验字幕正文；V3-1.1 的 `available` 不得冒充字幕下载或视频理解通过。

## 3. 开放接口边界

双源规则只位于 `BilibiliMediaPortalAdapter` 的内部页面状态解析器。通用 `MediaPortalAdapter`、`MediaPageContext`、消息名和 registry 均不增加 B站字段。未来 YouTube、小红书 adapter 必须各自实现平台事实解析，但复用同一 `available/unavailable/restricted/unknown` 合同。

## 4. 回归与出门条件

- 正例：API 字幕项；B站具体语言项 + 字幕制作者事实。
- 负例：标题/简介含“字幕”；通用字幕按钮；只有语言项；锚点 `BV1ZpYd66ELP`。
- 必须重跑 targeted unit、全量 Vitest、typecheck、build、静态权限审计和全新 12 页真实 Chrome run。
- 任一 ASR 样本被误判为 `available`、任一字幕样本缺少双源事实或需读取 Cookie 才能完成 V3-1.1 时，立即返回计划阶段。
