# V3-1.2-1 通用 Session 合同、注册表与 Broker 实施计划

日期：2026-09-17。状态：`APPROVED FOR IMPLEMENTATION`。

## 范围

新增 `session/contracts.ts`、`PortalSessionAdapter.ts`、`PortalSessionRegistry.ts`、`PortalSessionBroker.ts` 和 `validateMediaSessionContracts.ts`。使用 stub adapter/store/permission reader 完成单元测试，不接 Chrome API、不读 Cookie、不改 manifest、不挂 UI。

## 实施顺序

1. 按冻结 JSON Schema定义 TypeScript 合同与失败码闭集。
2. 实现 build-time 闭集注册表，重复 adapter/session ID 构造时立即失败。
3. 实现 Broker：policy/adapter/revision/scope/permission 前置复核后才调 adapter；异常只返回无秘密 `unknown` capability。
4. 实现语义校验器，覆盖 V3S-N-005..012 精确失败码。
5. 添加注册表、Broker、语义 fixture 测试并执行 typecheck/定向 Vitest。

## 停止条件

需要引入 B站 host/Cookie 名到通用文件；需要读取真实 Cookie；需要改变 Schema/registry；或测试只能通过放宽失败码时立即停止。
