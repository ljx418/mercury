# V3-1.2-2 Consent Policy Store 与 Permission Client 实施计划

日期：2026-09-17。状态：`APPROVED FOR IMPLEMENTATION`。

## 范围

实现 `MediaConsentPolicyStore.ts` 与 `PortalPermissionClient.ts`。Store 只持久化 Schema 白名单字段并按 revision 执行 grant/deny/revoke；Permission Client 只接受 build-time definition，调用注入的 permissions API，不接受调用方 origin/权限列表。

本子阶段不挂 UI、不读 Cookie、不改 manifest；真实 trusted click 在 V3-1.2-4/6 验证。

## 验收

- 默认 `not_granted`；grant/deny/revoke 状态、时间与 scope 精确。
- storage 输入/输出执行字段投影，秘密或额外字段不持久化。
- revision/policy/adapter 不匹配 fail closed。
- permission request 参数只能来自 adapter definition；返回 false 不写 granted。
- 定向测试、typecheck、PRD 检视通过。
