# V3-1.2-3 B站 Cookie Session Adapter 实施计划

日期：2026-09-17。状态：`APPROVED FOR IMPLEMENTATION`。

## 范围

在 `session/bilibili/` 内实现冻结 9 名 cookie 策略和 `BilibiliPortalSessionAdapter`。Chrome API 通过最小 `BilibiliCookieApi` 注入；adapter 仅派生 unique nonempty count、冻结 name-set hash 和 required `SESSDATA` 是否存在。

## 安全约束

- 只查询 `.bilibili.com`，并二次过滤 domain 与冻结 9 名。
- 不返回名称列表或值，不日志、不持久化；函数返回前释放局部数组引用。
- 即使绕过 Broker，policy/permission 不满足也不得调用 Cookie API。
- `available` 只表示 `SESSDATA` 非空，仍固定 `serverValidated=false`。

## 验收

真实 API 在 V3-1.2-6；本段用内存 API 验证 available/unavailable、错误、域/名称过滤、防御性门禁、返回 JSON 无秘密。定向 Vitest/typecheck 必须通过。
