# V3-1.2-4 Media Consent Card 与 Side Panel 挂载计划

日期：2026-09-17。状态：`APPROVED FOR IMPLEMENTATION`。

## 范围

实现通用 `MediaConsentCard`、严格消息客户端，并在 Side Panel 只对已注册且同时存在 page/session adapter 的门户显示。B站传入五项中文 scope copy；通用组件不含 B站 Cookie 名或 host。

授权按钮的 handler 必须先同步调用 `PortalPermissionClient.request`，再等待 Promise；拒绝、撤销、刷新走固定命令。V3-1.2-5 完成前消息路由尚未接通，因此本阶段以组件交互测试、typecheck 和挂载静态审计出门。

## 验收

- 五 scope 可见；未授权、拒绝、候选可用/不可用、撤销状态文案准确。
- 明确“会话候选，不代表服务端已验证，不向 Runtime 发送”。
- UI 不显示 Cookie 名/值；非注册门户不渲染。
- 授权/暂不授权/撤销/刷新均为真实按钮，焦点与状态区域可访问。
- 定向组件测试、typecheck 通过。
