# V3-1.2-5 Background Router 与可选权限实施计划

日期：2026-09-17。状态：`APPROVED FOR IMPLEMENTATION`。

## 范围

实现严格 `PortalSessionMessageRouter`，在 Background 组合 registry/store/permission/broker，并在 WXT manifest 只新增 `optional_permissions=[cookies]` 与 `optional_host_permissions=[https://*.bilibili.com/*]`。

## 门禁

- 只接受 runtime id 与 URL 都精确匹配的 extension Side Panel/Workspace 文档 sender；宿主页 content script、其他扩展和其他扩展页面一律拒绝。Chrome 可以给扩展文档附加 `sender.tab`，不得仅凭该字段误拒绝合法 Side Panel。
- 五个命令采用 exact-key 校验；额外 host/cookie/value 字段一律拒绝。
- `record_grant` 必须先复核 named+host permission；Background 绝不调用 permissions.request。
- `revoke_policy` 调用 remove 并复核两类权限都为 false 后才写 revoked。
- `inspect_capability` 只返回不含秘密的 broker result。

## 验收

路由正/负例、read count、sender 边界、manifest 精确差异、定向测试、全量 typecheck/build 通过。不得新增 required host 或 `<all_urls>`。
