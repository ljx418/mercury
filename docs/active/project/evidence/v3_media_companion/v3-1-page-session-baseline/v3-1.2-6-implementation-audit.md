## 4. 本轮修复

1. `MediaConsentCard` 用 pending focus 处理异步 busy 状态，拒绝、授权、撤销后分别恢复到稳定操作控件。
2. Cookie read 由绝对计数改为每次合法 inspect 的严格 `+1` 增量；拒绝、revision mismatch、撤销均必须 `+0`。
3. 重启语义按冻结合同改为“Chrome 实际权限为权威”：权限持久时重读；权限未持久时显示移除并保持 0 read。
4. verifier 不再只信任 `passed=true`，独立检查 required check IDs、攻击 observation、storage、焦点、截图、Axe 和重启分支。
5. 增加拒绝态截图，关闭结构化观察冒充视觉证据的缺口。

## 5. 假绿审计

- 未调用 CDP `grantPermissions`；授权来自真实点击和原生 Chrome 权限气泡。
- 桌面会话文件只在 collector 内存使用；产品代码、构建、证据中无文件路径读取能力。
- 未输出、持久化或 hash Cookie 值；只输出计数、布尔状态和服务端 code。
- 未把 `available/serverValidated=false` 扩大为产品服务端验证或可下载。
- 未因回归失败而放宽 V3-1.1 `subtitle available` 断言，也未把已登录全页截图混入匿名基线。
