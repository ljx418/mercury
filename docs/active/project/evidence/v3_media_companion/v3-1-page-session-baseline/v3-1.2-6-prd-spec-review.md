# V3-1.2-6 PRD 规格检视

日期：2026-09-17。结论：V3-1.2 会话能力与 V3-1R 登录态真实站点回归均符合 V3 PRD、目标架构和隐私边界；最终出门等待独立实施审计。

## 已达成

- B站为唯一 active portal；通用接口不依赖 bvid/cid，未来门户需要独立 adapter、权限和真实矩阵。
- 会话权限只由 Side Panel 可见按钮请求；Background 不代请求。
- 用户可见五项 scope、拒绝、授权、候选状态、重启后权限移除和撤销；状态不冒充服务端已验证。
- 合法 inspect 每次只读一次 Cookie；拒绝、revision mismatch、权限缺失和撤销均不读。
- Cookie 值未进入产品 storage/log/evidence；最终 644 文件、超过 101 MB 的扩大扫描 0 命中。
- required 权限未扩大；没有 `<all_urls>` 或其他门户权限。
- 真实服务端输入有效，匿名/登录/攻击/restart/revoke/可访问性链均通过。
