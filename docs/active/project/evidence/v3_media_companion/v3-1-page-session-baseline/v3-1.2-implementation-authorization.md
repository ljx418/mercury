## 2. 授权范围

- 实施 V3-1.2-0..V3-1.2-6：可选 Cookie 权限、通用门户 session 接口、B站 session adapter、授权 UI、Background 路由、真实 Chrome 验收和秘密泄漏扫描。
- 产品代码只允许从当前 Chrome Cookie Store 读取注册表白名单；不得读取文件系统中的 `myCk.txt`。
- `myCk.txt` 只允许由隔离的一次性验收进程读取，用于创建全新、可销毁的 Chrome 验收 profile；不得进入产品 build、Runtime、仓库、日志、截图、错误、证据包或审计包。
- 会话种子必须先在一次性 profile 中通过 B站真实服务端请求验证；未验证、失效、风控或区域受限时不得计入正例。
- 使用会话种子只能声明 `user_authorized_live_session_seed` 验收链通过，不得声明“人类手动登录链已验证”。
