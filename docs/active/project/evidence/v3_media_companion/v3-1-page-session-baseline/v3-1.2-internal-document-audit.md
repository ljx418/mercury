## 3. 三项 Minor

1. 语义负例当前是文档合同，尚无产品 validator 执行结果；这是 V3-1.2-1 的必做项，不得被本轮 shape PASS 覆盖。
2. 登录正例必须由人类在专用 profile 完成，因此实施后生产验收不能全无人值守。
3. `available` 只是候选会话能力；服务端有效性与 Browser→Runtime 秘密传输必须在 V3-1.3 另行审计。

## 4. 偏离与过度承诺检查

- 未改变 B站优先顺序，未将 YouTube/小红书加入当前生产分母。
- 未把登录 Cookie 存在解释为服务端有效，合同固定 `serverValidated=false`。
- 未把五项产品 scope、Chrome optional permission 和任务租约合并为一个布尔值。
- 未新增 `<all_urls>` 或等价权限，未恢复普通页面静态注入。
- 未使用 BiliNote 的明文 Cookie 存储，未授权整仓迁移。

## 5. 门禁

文档候选可进入外部独立文档审计。外审必须 Fatal=0/Major=0，且用户须在知道“扩展将可读 B站会话 Cookie，值只用于当次内存派生”的前提下另行批准高风险实施。在此之前不得修改 manifest optional Cookie permission 或实现 Cookie API 读取。
