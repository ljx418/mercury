## 为什么必须停止

验收计划 V3-1.2-A07 要求服务端 `code=0/isLogin=true`。继续重跑同一输入会稳定失败；删除该要求、只看 Cookie 存在或只看 UI badge 都会造成 semantic false-green。V3-1.3 会传输敏感会话，因此不能在 V3-1.2 未证明真实有效前启动。

## 恢复输入

需要用户从当前确实已登录 B站的专用浏览器会话重新导出同格式文件，覆盖桌面 `myCk.txt`，或在后续专用 disposable Chrome profile 中人工登录。无需向对话框粘贴 Cookie 值。

恢复后必须使用新 runId，从零执行服务端验证、原生权限、匿名/登录/revoke、A01..A15、秘密扫描、V3-1.1 回归和独立实现审计；不得复用或拼接本轮失败 run。
