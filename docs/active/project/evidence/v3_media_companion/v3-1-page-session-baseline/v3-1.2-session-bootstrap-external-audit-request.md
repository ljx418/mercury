# V3-1.2 实时会话引导补充条款外部审计请求

日期：2026-09-17。入口：`docs/active/project/external-audit-package/AUDIT_MANIFEST.md`。

## 决策问题

请独立只读审查：用户明确授权 `myCk.txt` 后，候选补充条款是否在不改变产品 Cookie 数据源、不降低零持久化/零泄漏门槛、不冒充人工登录、不扩大 V3-1.2 范围的前提下，足以支撑一次性真实会话验收。

## 必查项

1. 重算 manifest 全部载荷 SHA-256，并与权威源逐字节对账。
2. 确认产品代码仍只允许 Chrome Cookie Store，`myCk.txt` 路径只存在于授权/验收治理文档。
3. 确认 `user_authorized_live_session_seed` 不得声明 `human_manual_login`，且必须经服务端真实性验证。
4. 确认不输出/持久化 Cookie 值或值 hash，不复制主 profile，不接受非 B站域和注册表外名称。
5. 确认 Schema `serverValidated=false` 未被绕过，服务端探测只用于证明测试输入真实。
6. 确认 V3-1.3 envelope/lease、V3-2 下载和其他门户仍未授权。
7. 对 Schema、positive、12 cases、5 scopes、9 names、页面 registry 绑定和 Draw.io 结构做回归。

## 通过门槛

只有 `Fatal=0/Major=0` 才允许开始 V3-1.2-1 产品代码。Minor 必须标明 owner 与关闭阶段。不得把本次文档结论扩大为 V3-1.2 代码 PASS、人工登录 PASS、服务端会话产品验证或 V3-1/V3 PASS。
