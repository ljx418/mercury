## 2. 独立检查

1. `myCk.txt` 以只读脚本检查，未输出值、文件原文或值 hash：文件是 JSON 数组，26 条 cookie，全部属于 B站域；冻结 9 名均有非空值，`SESSDATA` 非空。

5. 原机器合同不需要新增秘密字段；`serverValidated=false` 仍由 Schema 固定。服务端探测属于输入真实性门槛，不是产品 capability 字段。
