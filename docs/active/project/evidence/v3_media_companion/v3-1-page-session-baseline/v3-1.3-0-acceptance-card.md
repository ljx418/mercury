# V3-1.3-0 合同与内部校验器验收卡

日期：2026-09-17。状态：`READY FOR IMPLEMENTATION`。授权来源：`v3-1.3-implementation-authorization.md`。

## 1. 子阶段目标

把已冻结的 transport registry、公开记录 Schema、positive 和 25 个 negative cases 映射成产品内可复用的 TypeScript/Python 合同与严格校验器。本子阶段不建立 HTTP endpoint、不读取 Cookie、不创建 channel/lease，也不改变 UI。

## 2. 实施范围

- 新增通用 credential transport 类型、公开记录类型和 FailureCode 枚举。
- 新增严格字段闭集、时间/TTL、跨记录 task/adapter/policy/binding/name-set 一致性校验。
- 新增与 25 个 fixture 对齐的合同测试；语义负例必须返回 exact FailureCode。
- B站 Cookie 名集合只允许由既有 plugin registry 引用；通用合同目录不得出现 `bilibili.com`、`SESSDATA`、`bvid` 或 `cid`。

## 4. PRD 检视

- 对齐 PRD：只建立“本机安全会话”的机器合同，不宣称媒体已获取或视频已理解。
- 不扩大权限：不新增 `<all_urls>`，不读取 filesystem Cookie，不接入通用 proxy。
- 不产生假绿：fixture 只证明合同层；真实 Browser-to-Runtime 秘密交换留在 V3-1.3-7 单一真实 run。

## 5. 出门条件

上述六项全部 PASS，Fatal=0、Major=0，并落盘 `v3-1.3-0-acceptance-result.md` 与 `v3-1.3-0-prd-review.md` 后，才允许开始 V3-1.3-1 Origin 探针、Runtime authenticator 和 channel store。
