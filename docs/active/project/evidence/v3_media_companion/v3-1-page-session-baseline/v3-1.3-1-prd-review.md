# V3-1.3-1 PRD 规格检视

日期：2026-09-17。结论：`ALIGNED / NEXT SUBSTAGE ALLOWED`。

- 用户目标：为“正在建立本机安全会话”提供强认证、短时、一次性的 Runtime capability；尚未显示“租约已就绪”。
- 安全边界：未放宽全体 `chrome-extension://`；秘密 endpoint 使用精确 extension Origin，主 bearer 只在 bootstrap 使用。
- 开放性：通用 store 接受策略注入；当前未注册 YouTube/小红书，无法获得 channel。
- 真实性：Origin 来自真实 Chrome，而非 TestClient 伪造；Runtime 全回归通过。
- 未实现：Cookie envelope、租约、媒体获取和视频理解仍未实现。

允许开始 `V3-1.3-2` UI channel client 与 trusted message schema；不得提前让 Background 获得主 bearer或读取 Cookie。
