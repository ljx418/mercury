# V3-1.3-3 Background B站 Envelope Broker 验收卡

日期：2026-09-17。状态：`READY FOR IMPLEMENTATION`。

## 1. 实施范围

- Background 在受信 exchange 后重新读取 policy、Chrome permission 与当前 B站 Cookie Store。
- B站 plugin 只保留冻结 9 名、合法 B站域、非空值，并要求 `SESSDATA`；构造严格 `BilibiliCredentialEnvelope/v1`。
- 专用 fetch 使用 `Navia-Media-Channel`、`redirect=error`、`cache=no-store`、`credentials=omit`，body ≤32768，单次调用、无同 body retry、无 body observation。
- 通用 `navia.runtimeFetch` 和 stream 明确拒绝三个 credential endpoint。
- 本阶段 Runtime lease endpoint 尚未实现；broker 集成测试使用只在调用栈内的非生产 marker 值，不能冒充真实验收。

## 2. 验收标准

| ID | 操作 | 必须结果 |
|---|---|---|
| `V3-1.3-3-A01` | policy/permission/capability 任一不满足 | exact fail closed；Cookie read 0 或 lease fetch 0 |
| `V3-1.3-3-A02` | 已授权 B站 session | Cookie API 精确一次；只输出冻结 9 名合法字段；required 缺失拒绝 |
| `V3-1.3-3-A03` | 专用 fetch | body 上限、专用 auth、no-store/error/omit；attempt=1 |
| `V3-1.3-3-A04` | 网络中断/5xx/响应丢失 | 原 body 不重试、不持久化；返回 transport failure |
| `V3-1.3-3-A05` | 通用 fetch/stream 三 endpoint | 在 Background fetch 前拒绝；无 request body observation |
| `V3-1.3-3-A06` | 开放性 | 通用 transport 0 B站常量；B站字段只在 plugin；未注册门户无 broker |
| `V3-1.3-3-A07` | 回归 | 新测试、全前端、typecheck/build PASS |

## 3. PRD 门禁

完成后只证明 Browser 端能安全构造并单次发送 envelope；Runtime 尚未持有 lease，UI 不得显示“已就绪”。
