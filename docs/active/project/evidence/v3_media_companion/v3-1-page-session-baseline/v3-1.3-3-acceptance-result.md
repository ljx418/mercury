# V3-1.3-3 Background B站 Envelope Broker 验收结果

日期：2026-09-17。结论：`PASS`。Fatal=0、Major=0。

## 1. 实施结果

- 新增 B站专用 `BilibiliCredentialEnvelopeBroker`；通用 credential 目录不承载门户名集合。
- exchange 按顺序复核 channel、policy、revision、scope、Chrome permission，再精确执行一次 Cookie Store read。
- 仅保留冻结 9 名、合法 B站 domain、非空值，required `SESSDATA` 缺失时不调用 Runtime。
- 专用 fetch 固定 one-shot/no-store/omit/redirect error/no-referrer/body 32768 上限；网络失败不重试。
- generic fetch/stream 在 fetch 前拒绝 channel/lease/revoke 路径。

## 2. 验收

| 验收项 | 实际结果 |
|---|---|
| A01 policy/permission | denial 在 Cookie read 前拒绝；fetch 0 |
| A02 白名单 | Cookie read=1；测试输入中非白名单/错误域被剔除；required 缺失拒绝 |
| A03 专用 fetch | 专用 Authorization、body/redirect/cache/credentials/referrer 全冻结；attempt=1 |
| A04 失败 | transport failure 只调用 fetch 一次；revocation handle 0 |
| A05 通用 proxy deny | channel/lease/lease-id/query 路径均识别；普通路径不过度拦截 |
| A06 开放性 | B站常量只在 plugin；未注册门户无 broker |
| A07 回归 | 定向 48 tests、前端全量 36 files / 279 tests、typecheck、E2E build 全 PASS |

## 3. 证据边界

测试仅使用显式 `test-only-*` marker，不是生产 Cookie，不构成真实 Browser-to-Runtime 验收。真实 Cookie 只允许在 V3-1.3-7 隔离 run 中使用。
