# V3-1.3-4 Runtime 严格 Envelope 与内存 Lease 验收卡

日期：2026-09-17。状态：`READY FOR IMPLEMENTATION`。

## 1. 实施范围

- `POST /v1/media/credential-leases` 先从专用 Authorization 取 ticket 并消费，再读取 body、检查 32768 bytes 和 JSON。
- 通用 validator 严格闭合 envelope 与 credential entry；门户 policy 注入 envelope type、session adapter、名称集合、required 名与域校验。
- `CredentialLeaseStore` 只在 Runtime 进程内持有 credential material，最长 60 秒；公开 lease 无名称、值、ticket 或 revocation token。
- response 单独返回 transient revocation token 供 Background 内存保存；`serverValidationStatus=not_performed`。

## 2. 验收标准

| ID | 操作 | 必须结果 |
|---|---|---|
| `V3-1.3-4-A01` | 正常 channel + strict envelope | 同 task/adapter/policy/revision/binding/hash；返回 active 60 秒 public lease |
| `V3-1.3-4-A02` | 公开 response 扫描 | 0 Cookie name/value/channel token/revocation token（revocation token 只在独立 transient 字段） |
| `V3-1.3-4-A03` | malformed/oversized body 后重试同 ticket | 首次请求即消费；第二次 exact replay；lease 0 |
| `V3-1.3-4-A04` | 篡改 task/adapter/policy/revision/binding/hash/name/domain/字段 | exact FailureCode；lease 0 |
| `V3-1.3-4-A05` | 重用 envelopeId + 新 channel | `V3_MEDIA_ENVELOPE_REPLAYED`；lease 不增加 |
| `V3-1.3-4-A06` | 内存 lease | internal resolve 需同 task；到期后 credential 引用删除；无 DB/EventStore/Trace 写入 |
| `V3-1.3-4-A07` | Runtime tests | 新单元/HTTP + Runtime 全量 PASS |
