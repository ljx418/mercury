# V3-1.3-4 Runtime 严格 Envelope 与内存 Lease 验收结果

日期：2026-09-17。结论：`PASS`。Fatal=0、Major=0。

## 1. 实施结果

- Runtime lease endpoint 在 body 读取/JSON decode 前消费 channel ticket。
- `CredentialEnvelopePolicy` 注入门户 envelope type、session adapter、policy、name set、required names 和 domain validator。
- `CredentialLeaseStore` 仅在进程内保存 credential list 与 revocation capability；公开 lease 固定最长 60 秒、`serverValidationStatus=not_performed`。
- envelopeId 在结构可识别后立即进入内存 replay set；新 channel 重用同 envelopeId 也被拒绝。

## 2. 验收

| 验收项 | 实际结果 |
|---|---|
| A01 正例 | 同任务/adapter/policy/revision/binding/hash；active 60 秒 lease |
| A02 公开边界 | public lease 0 Cookie material/channel token/revocation token；revocation capability 仅 transient sibling field |
| A03 首次消费 | malformed body 后同 ticket 返回 `V3_MEDIA_CHANNEL_REPLAYED`；lease 0 |
| A04 篡改 | task/adapter/policy/revision/binding/hash/name/domain/extra field 共 9 类 exact FailureCode PASS |
| A05 envelope replay | 新 channel + 相同 envelopeId 返回 `V3_MEDIA_ENVELOPE_REPLAYED`；lease 不增加 |
| A06 内存/过期 | internal resolve 要求同 task；61 秒后 credentials clear、active size=0 |
| A07 回归 | 专项 18 tests；Runtime 全量 266 tests PASS |
