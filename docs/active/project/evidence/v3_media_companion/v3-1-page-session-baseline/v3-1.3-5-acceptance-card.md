# V3-1.3-5 撤销、重启与清理验收卡

日期：2026-09-17。状态：`READY FOR IMPLEMENTATION`。

## 1. 实施范围

- `DELETE /v1/media/credential-leases/{leaseId}` 仅接受 transient revocation capability；公开 leaseId 不是授权。
- Background broker 在 policy revoke、Chrome permission removed、白名单 Cookie changed 时一次性 revoke，并无论网络结果都丢弃本地 handle。
- Runtime expiry/revoke/clear 必须清空 credential list；Background restart 丢失 binding/channel/revocation handle，Runtime 残余最多 60 秒。
- Runtime restart 后旧 channel、envelope replay cache 和 lease 均不可恢复。

## 2. 验收标准

| ID | 操作 | 必须结果 |
|---|---|---|
| `V3-1.3-5-A01` | 正确/错误/缺失 revocation capability | 正确清空并返回 revoked public lease；错误/缺失 fail closed |
| `V3-1.3-5-A02` | policy revoke | Background DELETE 一次；handle 删除；新 exchange 由 policy gate 拒绝 |
| `V3-1.3-5-A03` | permissions.remove / registered Cookie change | active leases revoke；非白名单或非门户 Cookie 不触发 |
| `V3-1.3-5-A04` | channel/lease expiry | 状态过期、秘密引用清空、不得复活 |
| `V3-1.3-5-A05` | Runtime/Background restart | Runtime store/replay 0；Background binding 变化且 handle 0；旧能力 fail closed |
| `V3-1.3-5-A06` | 网络失败 | revoke 不重试；本地 handle 仍删除；Runtime 残余受 60 秒限制 |
| `V3-1.3-5-A07` | 回归 | 前端/Runtime 新测试与全量回归 PASS |
