## 1. 实施结果

- Runtime `CredentialChannelStore` 在消费或过期后删除原始 channel token，仅保留进程内不可逆终态摘要以区分 replay/expired；公开记录仍可审计。
- Runtime `CredentialLeaseStore` 在 expiry/revoke/clear 时清空 credential list 与 revocation token。
- `DELETE /v1/media/credential-leases/{leaseId}` 仅接受 `Navia-Media-Revoke` 临时能力；公开 leaseId、缺失或错误能力均不能撤销。
- Background 在产品 policy revoke、Chrome `cookies`/B站 host permission 移除、冻结白名单 Cookie 变化时撤销全部本进程 lease；非注册门户和非白名单 Cookie 不触发。
- Background 在发出 DELETE 前删除本地 handle，网络失败不重试，Runtime 残余由 60 秒 TTL 限制。
- 新 Runtime store 与新 Background session binding 均不恢复旧能力。
