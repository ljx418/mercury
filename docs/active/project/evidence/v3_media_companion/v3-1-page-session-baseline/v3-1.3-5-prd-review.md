# V3-1.3-5 PRD 规格检视

日期：2026-09-17。结论：`PASS / NO SPEC DRIFT`。

## 1. 对齐项

- 生命周期严格保持 20 秒一次性 channel 与最长 60 秒 Runtime 内存 lease。
- 撤销由 policy、浏览器权限和已注册 Cookie 变化触发；未新增自动下载、媒体访问或后台分析。
- 公开 lease 仍不含 Cookie 名/值、channel token 或 revocation token。
- B站规则仍位于 portal plugin；通用 channel/lease store 未加入 B站字段。
- 网络不确定时不重放 envelope 或 revoke body，符合 fail-closed 与最小秘密驻留要求。

## 2. 风险复核

- 错误撤销能力不会删除 active lease，避免以公开 leaseId 作为授权。
- 已消费 channel 原始 token 不再由 store 长期持有；终态区分使用进程内 SHA-256 摘要，重启即清空。
- Background 撤销网络失败时 Runtime 最多保留至 TTL；此残余窗口是冻结 ADR 明示边界，不是成功撤销声明。
