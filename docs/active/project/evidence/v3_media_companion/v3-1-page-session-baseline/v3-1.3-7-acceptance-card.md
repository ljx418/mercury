# V3-1.3-7 真实 Chrome + Runtime 出门验收卡

日期：2026-09-17。状态：`READY FOR IMPLEMENTATION`。

## 1. 实施范围

- Side Panel 与 `#/media/current` Workspace 只接线“开始分析 -> 建立安全会话 -> 租约已就绪/失败”；就绪后固定提示“媒体获取将在 V3-2 提供”。
- 使用全新 build、Runtime 进程、隔离 Chrome profile、全新 runId 和用户已授权的 live B站 Cookie seed；不得复制主 profile或写入 seed。
- 在同一 run 执行 V3-1.3-A01..A20、四视口、键盘、Axe、replay/expiry/revoke/restart/fault、全介质 raw-value scan 和 cleanup。

## 2. UI 门槛

- 开始按钮必须来自真实用户点击；未授权/无 Runtime token/无 capability 均 fail closed。
- `establishing/ready/failed` 同时有文字和 `aria-live`，不只依赖颜色；完成后焦点返回开始按钮。
- UI 不显示 leaseId、token、Cookie 名/值、账号身份；ready 不得写成登录有效、媒体已获取或分析完成。
- Side Panel 360/420 与 Workspace 768/1280 无横向溢出，Axe serious/critical=0。

## 3. 真实数据门槛

- live seed 只注入隔离 profile Cookie Store；服务端预检确认当前授权会话可用，但公开 lease 仍固定 `serverValidationStatus=not_performed`。
- Background 实际 Cookie read 一次；Runtime active lease 一条；公开响应无秘密。
- 真实值仅在 scanner 内存作 needle，build/profile 导出以外的 storage/DB/EventStore/Trace/log/error/retry/screenshot/archive 0 命中；run 结束关闭进程并删除 profile。

## 4. 停止条件

任一真实 secret 命中、Axe serious/critical、跨 run 拼接、需降低合同门槛、需实现 V3-2 媒体获取、或无法证明 Runtime restart 清空 lease，立即停止并输出风险记录，不得生成 PASS。
