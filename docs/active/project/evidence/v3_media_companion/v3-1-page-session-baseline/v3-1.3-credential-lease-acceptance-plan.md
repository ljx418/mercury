# V3-1.3 一次性凭据通道与短租约验收计划

日期：2026-09-17。状态：`DOCUMENT CANDIDATE / EXECUTION NOT AUTHORIZED`。

## 1. 单一生产输入

- 一个全新 extension build、一个全新 Runtime 进程、一个全新专用 Chrome profile 和一个新 runId。
- Runtime 使用随机 32+ 字节 bearer 与当前 build 的精确 extension ID；二者只存在环境/人工输入与进程内存。
- 专用 profile 的 B站会话证据类只允许 `human_manual_login` 或已获授权的 `user_authorized_live_session_seed`；不得复制主 profile、不得把种子文件放入 run 或审计包。
- 正例使用固定锚点 `https://www.bilibili.com/video/BV1ZpYd66ELP`；负例在同 run 的隔离 segment 中执行，不与旧 V3-1.2/V3-1R run 拼接。
- 本阶段不下载媒体；任何字幕/音视频产物计入本阶段成功均为假绿。

## 3. 生产证据

单 run 至少包含：build index、registry/schema/fixture hash、Runtime 环境的非秘密 binding 摘要、channel/lease 公共记录、failure observations、Cookie API read count、lease-store counters、restart/revoke observations、四视口截图、Axe/keyboard、cleanup manifest、secret scan、PRD review、false-green audit 和 sealed raw result。

不得包含：Runtime bearer、channel/revocation token、Cookie 名列表/值、账号/昵称/UID、profile 路径、完整 B站顶部账号区域、envelope 原始 body、可逆 secret hash。

## 4. False-green 拒绝规则

- 只验证 public Schema 而不真实发送 secret envelope，Major。
- 用 fake Cookie、产品 `chrome.cookies.set`、旧 run、跨 run 拼接或手改 lease，Fatal。
- 把任意 `chrome-extension://` CORS 视为认证，或把 generic proxy 当秘密 transport，Fatal。
- 为重试保存/复发原 body，或从日志/E2E observation 还原 body，Fatal。
- 只看 lease UI badge而不独立检查 Runtime memory store、expiry/replay/restart/revoke，Major。
- 以 Cookie 值 hash 代替 needle 扫描，Major；保存该 hash，Fatal。
- 将 `serverValidationStatus=not_performed` 宣称为 B站登录有效或媒体可获取，Major。
- 为通过而放宽 channel/lease TTL、body 上限、Origin、adapter、host 或 Cookie 名，Fatal。
