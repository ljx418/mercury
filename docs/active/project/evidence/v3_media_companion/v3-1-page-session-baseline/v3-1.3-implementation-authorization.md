## 3. 已授权的高风险边界

- 使用现有内存 Runtime bearer 从受信 Extension 页面创建 20 秒一次性 channel。
- Background 在重新校验 policy、permission 与 capability 后，从 Chrome Cookie Store 读取 B站冻结白名单并通过专用 loopback envelope 传给 Runtime。
- Runtime 仅在进程内持有凭据并签发最长 60 秒、无秘密字段的短租约；允许实现重放拒绝、过期、撤销、重启清理和秘密扫描。
- 可在隔离的真实 Chrome 验收进程中读取用户已授权的 B站会话种子文件，仅用于创建可销毁专用 profile；产品代码不得读取该文件。

## 4. 仍未授权

- V3-2 或之后的媒体获取、字幕/音视频下载、cookiefile、ASR、OCR、VLM、图文大纲或视频理解。
- YouTube、小红书等门户的实际 adapter；V3-1.3 只保留接口扩展点，不得声明已适配。
- 扩大 Cookie 名、host、Origin、TTL、body 上限或使用通用 Runtime proxy 承载秘密。
- 把 Runtime bearer、channel/revocation token 或 Cookie 值写入 storage、URL、日志、证据、Trace、EventStore、异常、重试队列或公开响应。

## 5. 强制停止条件

任一情况发生即停止并回到文档/风险审计：真实 Chrome Origin 缺失或不稳定而需要放宽 Origin；秘密扫描非零；无法证明 channel 第一次请求即消费；需要重发同一 envelope；需要持久化凭据；需要改变冻结合同；真实数据验收不能满足 A01-A20。
