# V3-2-0b-5.3-5 PRD 规格检视

真实结果证明路线 A 不能满足 V3-2-A06 的完整语音分母。sample03/chunk4 在 `vad-maxseg=15s`、`30s` 和无 VAD 三种模式均为 0 segment，不能归因于 Adapter 参数；该窗口有显著非零音频，不能标静音或 N/A。

20/30 秒上下文诊断可产生 segment，但它会改变冻结的 8x15 秒输入合同，并带来跨窗口文本重复、segment 跨边界、时间裁剪失真和双盲 bin 对齐风险。未经新 ADR/合同/负例/外审直接采用会构成 Major 规格偏移与假绿。

结论：路线 A 当前实现无用户体验回退，因为未被标记 qualified、设置页仍回退 Tiny；但 V3 视频理解主路径仍被 A06 阻塞。5.3-6/7 不得开始。
