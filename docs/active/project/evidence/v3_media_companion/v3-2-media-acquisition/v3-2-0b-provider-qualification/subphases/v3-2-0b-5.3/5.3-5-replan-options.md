# V3-2-0b-5.3-5 失败后的技术路线

## 决策结论

持久 worker 只能降低重复模型加载成本，不能修复已经在单独 15 秒输入上稳定出现的 0 segment，因此不再是根因修复路线。

| 路线 | 技术成本 | 架构成本 | 体验风险 | 判断 |
|---|---|---|---|---|
| A2 上下文辅助 Paraformer | 中：20/30 秒重叠推理、中心归属、去重/冲突检测 | 高：必须新增 context-window、segment ownership、不可改写证明与 24-bin 新合同 | 高：无词级时间戳，跨 15 秒 segment 难以诚实裁剪，易重复或漏字 | 仅研究，不推荐直接生产 |
| C 新本地低资源 Provider（SenseVoiceSmall 候选） | 高：新 binary/model、Adapter、安装与三平台验证 | 中：现有 Provider registry/TaskAudioRef 可复用，但需全新资产、许可、威胁模型与 A01..A20 | 中：可能提升中文覆盖，但资源/时间戳/质量均未实测 | **推荐进入文档与真实 spike** |
| B Faster-Whisper 更高档 | 高：更大模型与运行依赖 | 低到中：现有多 Provider 设计可承载 | 高：可能违反当前 512MiB/低资源目标 | 暂缓，除非用户接受资源门槛变化 |
| D 维持 Tiny fallback | 低 | 低 | 无新增回退；但 V3-2-A06 永久阻塞 | 安全停止方案 |

推荐下一步只批准“路线 C 文档冻结 + 资产/许可/最小真实 spike”，不得直接批准生产实现。需先证明安装体积、8GiB/no-GPU、时间戳、三样本 24-bin 非空和双人质量均可达成；失败仍保留 Tiny fallback。
