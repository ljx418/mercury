# V3-2-2 Route B 自然无字幕样本风险停止

日期：2026-10-06。决定：`FAIL / REPLAN`，停止 V3-2-2 出门审查与后续 V3-2-3。

## 1. 触发事实

- `v3-2-route-b-20261006T190000Z`：`BV13W41137qV` 同一 run 双探测均为 0 字幕，间隔 44 秒；真实获取完成 7 subtitle / 3 media / 1 blocked / 1 degraded。
- 随后发现 downloader 仅在发布时检查配额，生成阶段缺少硬文件大小上限。实现已增加 yt-dlp `--max-filesize` 与 ffmpeg `-fs`，69 聚焦和 441 全量 Runtime 回归通过。
- 因 build tree 已改变，`190000Z` 候选被主动撤回，不可扩大为修复后实现证据。
- 修复后的全新 `v3-2-route-b-20261006T200000Z` 中，同一自然样本当前出现 1 个字幕项。按 RB04 与防假绿规则直接失败；该 run 未执行媒体获取、未生成 Revision 4、未 seal。

## 2. 为什么不能自动继续替换

B站会异步增加 AI 字幕。Route B 已发生两次不同平台漂移：旧 injected 样本失去字幕、当前 natural 样本新增字幕。继续从候选池寻找“此刻为 0”的 URL，无法证明它在复验时仍自然无字幕，并会把验收变成时间窗口挑选，存在重大假绿风险。

## 3. 备选路线

| 路线 | 规格 | 优点 | 成本 / 风险 |
|---|---|---|---|
| B1 严格固定自然样本 | 改选当前仍 0 字幕的短视频，双探测后完整重跑 | 不改既有 Route B 分母 | 很可能再次被异步字幕破坏；复验不稳定，推荐度低 |
| B2 自然事实证明改为受控自有素材 | 在 B站发布并控制一个明确无字幕、无自动字幕的验收视频，仍走真实门户/媒体 | 可重复、仍证明自然无字幕 | 需要用户/项目拥有可控 B站素材及发布权限；外部依赖仍存在 |
| B3 将自然门槛移出固定 URL | 预冻结候选池与选择算法，同 run 自动选唯一无字幕项；若 0 或 >1 则失败 | 对单 URL 漂移更有韧性 | 规格与 schema/审计复杂度上升，需防 cherry-pick；属于重大规格修订 |
| C 全部使用审计故障 | 3 个 ASR trigger 都基于真实字幕发现后受控失败 | 最稳定、完全可复验 | 放弃“自然无字幕”真实场景，改变用户已批准的 Route B 核心分母，不可自动决定 |

推荐路线：B2；若无法提供可控素材，则 B3 优于持续替换固定 URL。B1 只适合一次性演示，不适合作为可复验出门门禁。

## 4. 当前门禁

- `190000Z`：SUPERSEDED / WITHDRAWN（修复前 build tree）。
- `200000Z`：FAIL（RB04，natural subtitle count=1）；禁止补 Registry/seal。
- V3-2-2：FAIL / REPLAN。
- V3-2-3、V3-3..7：BLOCKED。
- 需要用户选择 B2、B3 或 C；在此之前不再替换样本或运行真实获取。

**自动化开发停止原因：自然无字幕固定样本在修复后全新 run 中发生平台字幕新增，继续自动换样本会产生重大规格漂移和虚假验收风险。**
