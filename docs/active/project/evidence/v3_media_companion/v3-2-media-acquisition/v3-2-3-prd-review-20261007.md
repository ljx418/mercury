## 规格冲突闭环

Stage Gate 与总设计计划曾保留 Revision 3 的“自然无字幕 ASR 样本 <=1200 秒”旧约束，而当前 PRD 与用户接受的 Route B/B3 ADR 已冻结 Revision 5 能力槽位。现已明确：1200 秒只属于 Revision 3 历史矩阵；Revision 5 允许长媒体，但不得放宽 8 CPU、8 GiB、无 GPU、串行与全长转写门槛。当前最长样本在 2.63 GiB RSS 下完成，未以“机器可跑完”替代资源门槛。

## 偏移检查

- 未新增强制 ASR 用户按钮，生产仍优先真实可用字幕。
- 验收故障只在 runner 可达，Runtime/API/Acquirer 静态命中 0。
- 未引入云端 ASR、联网换模、自动正文修复或跨模型回退。
- 未把 transcript 正文放入公开证据，也未要求人类听写。
- 未把 V3-2-3 候选扩大为 V3-2/V3 或视频理解通过。

结论：Fatal=0，Major=0，Minor=2。Minor：组织独立性仍需外部 reviewer；SenseVoice 是 `development_baseline`，主观质量只在后续已冻结阶段处理。
