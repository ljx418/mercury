# V3-2-7 单 run 出门威胁模型

日期：2026-10-06。

| 假绿/风险 | 强制拒绝 |
|---|---|
| 跨 run 拼接成功样本 | 每个 artifact 绑定同 run/build/profile/runtime/root；不一致即失败 |
| 12 页缩分母或重分类 | Revision 3 hash + ID/URL/identity 唯一 + 6+3+1+1+1 精确复算 |
| fixture/mock 计生产 | 生产 evidence class、真实 Chrome target、Runtime observation 和 artifact hash |
| 复制旧 UI/fault receipt | receipt run/build 必须等于当前 run 派生 segment binding |
| secret 进入公开包 | 原值双层扫描，公开 tar member allowlist |
| cleanup 后仍有进程/profile/root | PID/track/socket/file/profile 四面扫描均为零 |
| candidate 自我批准 | candidate 固定 false/pending；独立审查另写不可变结论 |
| 扩大到视频理解/V3/其他门户 | allowed claim 精确文本；出现越界关键词即 Major |

审计基础设施超时不等于产品失败，也绝不等于通过；保留候选 pending 并重新独立审查。
