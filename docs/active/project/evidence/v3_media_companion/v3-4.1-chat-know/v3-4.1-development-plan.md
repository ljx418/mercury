# V3-4.1 Chat / Know 真实闭环开发计划

日期：2026-10-11。状态：`AUTHORIZED`。

## 目标

在不替换既有 V3 媒体主干的前提下，新增真实 `KnowledgeDraft -> KnowledgeItem` 本地事务。Chat 负责从当前网页上下文创建、编辑、取消、显式保存草稿；Know 负责真实列表、详情编辑、排序、生命周期和普通删除。V4 Query/Graph/Durable Forget 不进入本阶段。

## 实施顺序

1. 冻结 `KnowledgeDraft`、`KnowledgeItem`、错误码和 SQLite 迁移。
2. 在 Local Runtime 增加独立 `knowledge_v3` 模块及 REST API；默认即真实本地 SQLite，不读取 V2 mock adapter。
3. 扩展 `runtimeClient`，禁止前端直接持久化。
4. Chat 用草稿编辑器替换 Mock 保存卡；取消不落 Item，确认保存只产生一个 Item。
5. Know 使用真实 Item 列表/编辑器；支持标题、摘要、正文、标签、自定义字段、优先级、`active/aging/archived`、排序、来源打开和普通删除。
6. 生产一级导航只保留 Chat/Know；Settings 为辅助入口；Agent/Debug 仅开发构建可见。
7. 完成 Runtime、前端、重启一致性和真实 Chrome 流程，再做 PRD 检视。

## 边界

- 不自动保存，不把 Draft 当 Item。
- 不宣称语义 Query、Graph、自动老化或 Durable Forget。
- 不上传知识正文；全部保存在 Runtime SQLite。
- 不修改既有 V3-1..V3-5 历史 run。
