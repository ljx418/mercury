# V3-4.1 PRD 规格复核

## 结论

实现未替换或废弃既有 V3 媒体计划，只在既有 Chat / Know 信息架构上补齐真实持久化闭环。

| PRD 目标 | 结果 | 边界 |
|---|---|---|
| Chat 识读当前页面 | 保持已有实现 | 本阶段不重写页面提取 |
| Chat 知识提纯 | 草稿可编辑、取消、确认 | 不自动静默保存 |
| 保存后进入 Know | 原子、幂等、本地 SQLite | 不写入旧 mock adapter |
| Know 查看与编辑 | 已实现 | 单一本地存储 |
| 自定义与排序 | 标签、自定义字段合同、四种排序 | UI 暂未提供自定义字段编辑器 |
| 老化管理 | 显式 active/aging/archived | 自动调度属于后续阶段 |
| 来源可追溯 | sourceRefs + 打开来源 | 仅 http/https |
| 本地删除 | 单条本地删除 | 不扩大为 Durable Forget |
| Agent 远期规划 | 生产导航隐藏 | 未删除既有开发代码 |

规格偏差：无 Major。`customFields` 后端合同已支持但当前 UI 未暴露编辑器，记录为后续体验补强，不影响本阶段“自定义标签与生命周期”最低闭环。
