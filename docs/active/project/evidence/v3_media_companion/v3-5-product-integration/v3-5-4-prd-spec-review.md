# V3-5-4 PRD 规格检视

日期：2026-10-09。结论：`无 Fatal / 无 Major 规格偏差`。

## 覆盖结论

- 用户可围绕当前视频成品提问；有证据时显示回答与可回跳引用，无证据时明确拒答，不把常识或模型猜测伪装成视频事实。
- 用户可从大纲、时间线、导图、Ask 引用和 Evidence Drawer 返回同一 B站播放单元；跳转后读取真实播放器位置确认，而非仅验证调用成功。
- 用户可下载 JSON 或 Markdown ZIP；导出物绑定 task/revision/hash，明确“知识导入延后到 V4”，未把本地导出误报为 Know 入库。
- Cookie、API key、私有路径、原始媒体和回答正文均未进入公开审计材料；跨页面回跳 fail-closed。
- portal、播放器控制、Ask 和 export 分层保持开放，可由后续 portal adapter 扩展到其他站点。

## 未扩大承诺

- V3-5-4 不声明 V3-5 总体验通过；四视口、Axe、键盘与人工 H01–H10 尚待 V3-5-5/6。
- Ask 是低资源、证据抽取式实现，不承诺开放域推理或 V4 知识库问答。
- 导出不等于保存到 Know；存量知识管理与 Agent 仍不属于 V3 完成范围。

## 剩余风险

- Minor-1：真实数据矩阵仍为一个固定 B站视频；多站点只验证接口开放性，未验证生产适配。
- Minor-2：回跳样本均位于 0 秒附近；绝对时间绑定机制已真实回读，但长视频多时间段体验应在后续生产矩阵扩充。
