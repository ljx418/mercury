# V3-5.1 真实时间线碰撞产品失败记录

日期：2026-10-10  
目标 run：`v3-5.1-production-candidate-20261010T210000Z`

## 失败事实

- 第一个固定长视频已通过章节 seek、滚轮横移、鼠标拖动、适应全片和播放游标检查。
- 点击第一个 `moment` 时，位于同一视觉轨道的后续节点遮挡其按钮；真实 Playwright 指针连续重试后仍无法命中目标。
- 根因是时间线固定使用 `index % 3` 分轨，而长视频在 900px 基础画布上把相隔数分钟的 160px 卡片放到同轨重叠区域。
- 这是产品交互缺陷，当前候选整轮作废；不得用 `force: true`、DOM `.click()` 或只做键盘点击绕过。

## 修复设计

- 保持时间戳到横轴的真实比例。
- 按卡片实际宽度执行确定性贪心分轨；同轨相邻卡片必须至少相隔 172px。
- 若超过三轨，自动扩展横向画布并重新分轨；同一时间戳的多节点允许增加轨道，不相互遮挡。
- 时间线 viewport 高度随轨道数稳定计算，滚轮、拖动、缩放、适应画布和播放器游标合同保持不变。

## 重验要求

- 组件测试验证密集时间点在同轨不重叠，并验证同时间戳节点可分到独立轨道。
- 重新 build 后，从三个视频完整分母起点执行，不复用本轮任何 seek。
