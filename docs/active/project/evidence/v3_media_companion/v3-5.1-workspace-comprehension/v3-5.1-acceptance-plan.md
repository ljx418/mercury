# V3-5.1 Workspace 理解质量与交互验收计划

日期：2026-10-10。状态：`DOCUMENT CANDIDATE / IMPLEMENTATION NO-GO`。

## 1. 真实样本

- 固定 3 个结构不同的真实 B站视频：现有锚点、教程/演示、叙事/评论；V3-5.1-1 开始前 probe 冻结 URL/BVID/CID/时长/hash。
- 至少一个 >=30 分钟；每个样本当次生成 transcript、frame/OCR/vision evidence 和新投影。
- Cookie/API key/原媒体/私有截图不进入公开 evidence；BiliNote 输出、mock、fixture 只可做回归，不能计入 production 分母。

## 2. 自动门槛 A01..A20

| ID | 用户场景与机器操作 | 必须结果 |
|---|---|---|
| A01 | 打开三样本 fresh task | task/revision/source/outline 身份闭合 |
| A02 | 生成章节 | 每视频 3..12 顶层语义章节，顺序单调、不交叠、不用固定分钟窗凑数 |
| A03 | 展开章节 | 每章 >=1 key point 和 evidence；标题/论点非首句机械复制 |
| A04 | 查看代表帧 | 有 frame 的章显示真实受控缩略图；无 frame 诚实显示文本态 |
| A05 | 切换三视图 | outline/timeline/mindmap 同 outlineId/evidence catalog |
| A06 | 浏览时间线 | 可见总时长、刻度、章节带、>=8 moments、frame cards 和 cursor |
| A07 | 滚轮/拖动/缩放/fit | 四种操作可用且不劫持页面外滚动；销毁后 0 listener/timer 残留 |
| A08 | 播放视频 | 1 秒内更新 cursor/current chapter；切换 source 立即停止 |
| A09 | 查看图文大纲 | 章节、关键点、frame、证据类型与时间入口清楚且可折叠 |
| A10 | 操作导图 | root/chapter/key-point >=3 层，无环/孤儿；pan/zoom/collapse/fit 可用 |
| A11 | 键盘使用导图 | ARIA tree 可完成展开、移动、seek，不依赖 pointer |
| A12 | 五类入口各点两次 | >=10 次真实 seek，readback delta <=2 秒且 identity 一致 |
| A13 | 提 6 个 factual 问题 | 每个 answered block 有支持结论的同 task citation |
| A14 | 提 2 个 visual 问题 | citation 至少包含 frame/OCR/vision evidence，不以字幕冒充画面 |
| A15 | 提 2 个 cross-chapter 问题 | 检索覆盖 >=2 章，答案有逐块引用，不是简单拼接两段原文 |
| A16 | 提 2 个不足问题 | 2/2 `insufficient_evidence`，answerBlocks 为空 |
| A17 | 复核 12 问 | critical meaning error=0，citation 支持率 >=90% |
| A18 | 禁用/撤销云文本授权 | 0 派生文本网络调用；本地回退仍可用；原媒体上传恒 0 |
| A19 | 360/420/768/1280 + Axe/keyboard | 无遮挡/根溢出；Axe serious/critical=0；主路径键盘完成 |
| A20 | 8 GiB/no-GPU/CSP/bundle | 首交互 <=2s，持续主线程阻塞 <200ms，0 CDN/eval/remote script，依赖许可/hash 可审计 |

## 3. 合同与负例

运行 `v3-5.1-semantic-verifier.py`：schema meta、positive、20 个 registry 对应 negative 必须全 PASS。实施后新增生产 mutation，不得用当前 fixture mutation 数替代真实 mutation 分母。

## 4. 最小人类体验复核

自动 A01..A20 全绿后，人类只需在一个真实视频执行：拖动时间线、点击截图跳转、展开章节、点击导图节点、提一个跨章节问题。记录结构清晰度、操作顺畅度、答案有用性；人类不听写、不提供 Cookie、不读日志、不判断 hash。任一核心操作无法完成即 BLOCKED。

## 5. 出门
