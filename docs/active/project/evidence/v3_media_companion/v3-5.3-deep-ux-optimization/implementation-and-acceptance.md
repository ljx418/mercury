# V3-5.3 深度交互优化实施与验收记录

日期：2026-10-11

## 1. 范围与边界

- 同一媒体任务、同一 evidence catalog、同一已选 LLM Provider；未引入第二数据源或并行模型结果。
- Runtime 媒体 API、隐私合同、Cookie/凭据通道和原始证据均未修改。
- 只扩展前端呈现与既有提示词；旧投影继续使用旧列表视图回退。
- 未使用生图补造视频证据。所有可见截图来自任务已封存的私有 frame evidence。

## 2. 实施内容

### Chat 当前页总结

- 主操作从“读取当前页面 → 提交上下文 → 总结”收敛为“总结当前页”一次点击。
- 读取、同页复用、提交和总结仍由既有 `ensurePageContext()` 自动执行。
- 手工读取/提交移入“上下文诊断”，仅供失败恢复。
- 总结提示词明确正文识别、全局主旨、逻辑要点、依据/限制和视频详情页边界。

### Media 概览与大纲

- 概览增加视频结构、主要表达、关键依据和折叠的时间戳转写。
- 当前 ASR 不具备多人声纹分离，界面明确显示“说话人（单轨）”，不伪造 speaker identity。
- 大纲提供视频章节、知识长文、图文笔记、深度专栏四种前端呈现；切换不重新调用模型。
- 每章优先按时间区间聚合同一 evidence catalog 中的多张真实 frame，聚焦后展开；区间内无帧时使用离章节中点最近的真实帧并显式标注“邻近画面”，不伪造精确时间命中。

### 时间线与导图

- 时间线使用 `vis-timeline`，支持章节分组、拖动、滚动、缩放、适应全片和节点反跳。
- 导图使用 `@xyflow/react`，支持自由画布、拖动节点、缩放、小地图和逻辑关系边；默认聚焦主题与前几章，避免全图适配导致节点不可读。
- 保留键盘树作为无障碍等价路径。
- 缩略图增加 loading / failed / retry 状态，禁止静默退化。
