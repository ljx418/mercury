# Risks, false-green controls, and stop rules

| Risk | Control |
|---|---|
| WP-B/Stage B name confusion | use `WP-B Local Import` and `GC-B5R` explicitly |
| restricted fixed videos replaced by normal videos | frozen registry; no substitution; blocked stays in denominator |
| generic local seed bound to another BVID | exact task/source binding and negative composition test |
| local import treated as internal test shortcut | drive public product composition; direct store/controller calls are component evidence only |
| tabCapture silently returns as dependency | default-off assertion; no capture runner in GC-B5R path |
| Provider result shopping | one Provider/task; reject multiple attempt authorities |
| short/weak brief cosmetically repaired | composer allowlist unchanged; no paraphrase/pad/truncate/fabricated claim |
| old artifact reused | fresh namespace and authority hashes; cross-run reuse rejected |
| secrets or raw media leak | payload counters plus serialized payload and evidence scans |
| frozen hash churn creates repeated audits | report once; Codex refreezes once after stable candidate if authorized |
| expensive acceptance repeats | offline checkpoint first; one fresh six-video run and one visible batch later |
| user focus/audio disruption | no Chrome in offline work; later owned Chrome always `--mute-audio` and one announced batch |

Immediate stop requires a public/security contract change, denominator change,
new Provider authorization, raw-media cloud transfer, local directory scanning,
source-identity override, or need to modify historical evidence. Environment
unavailability is reported as preflight state and does not authorize a shortcut.
