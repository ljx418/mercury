## 3. API 形状

```text
GET  /v1/media/tasks/{taskId}/comprehension?revision={n}
POST /v1/media/tasks/{taskId}/comprehension:materialize
POST /v1/media/tasks/{taskId}/ask-v2
GET  /v1/media/tasks/{taskId}/evidence/{evidenceId}/thumbnail
```

- `materialize` 必须带 `expectedRevision`；冲突返回 `409 V351_REVISION_CONFLICT`，不得覆盖新版。
- thumbnail 只接受 kind=frame、同 task 且在 evidence catalog 内的 ID；`Cache-Control: private`，响应不含文件路径。
- Ask 请求固定 `taskId/expectedRevision/outlineId/question`；answered 每个 block 至少一个同 task citation，insufficient 的 blocks 必为空。
- 页面播放游标不写 EventStore，只存在浏览器任务期内存；刷新后重新 readPlayback。

## 5. 数据迁移与兼容

数据库只新增版本化 projection/event 类型，不改写 v2 行。旧任务没有 v3 comprehension 时，UI 显示“重新生成结构化视图”，不把 v2 固定时间窗静默标成语义章节。V3-6 fresh run 只接受 v1 comprehension candidate；历史 V3-5 仍可只读打开。

## 6. 云端文本边界

默认 `groundedTextCloudStatus=disabled`，provider/model/hash 均为 null，全部 Ask 为 `local_deterministic`。未来用户另行授权后，只允许发送 task-scoped transcript/OCR/VLM 派生文本；禁止发送 Cookie、API key、原音频、原视频、文件路径。撤销后不再发新请求，既有输出保留 provider/model/hash 标注但不冒充本地结果。
