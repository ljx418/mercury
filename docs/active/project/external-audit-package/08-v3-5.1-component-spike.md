# V3-5.1 开源组件隔离 Spike 决策

日期：2026-10-10。状态：`SPIKE COMPLETE / IMPLEMENTATION NO-GO`。

## 1. 候选与实测

| 组件 | 版本 | 许可 | npm unpacked | 本地 tar | 决策 |
|---|---:|---|---:|---:|---|
| `vis-timeline` | 8.5.4 | MIT 或 Apache-2.0 | 77,798,262 B | 16,578,581 B | 条件采用 |
| `markmap-view` | 0.18.12 | MIT | 86,454 B | 22,865 B | 采用 view 层 |
| `markmap-lib` | 0.18.12 | MIT | 741,061 B | 未纳入生产基线 | 暂不采用 |

`vis-timeline` 包的大部分体积来自 examples/docs/source maps；实际 standalone min JS 约 548,806 B、gzip 约 156,474 B，CSS 约 19,837 B。实现阶段必须以 Extension production bundle delta 为准，不可用 npm unpacked 或本表替代最终测量。

## 2. 采用条件

1. 只导入 npm 锁定版本，不使用 CDN、远程脚本或 eval。
2. `vis-timeline` 禁止 editable/add/update/remove；pointer drag 只平移 viewport，点击只产生 Navia seek intent。
3. 用 React wrapper 显式 destroy instance、取消 listener/timer；task/revision 变化时重建受控 dataset。
4. `markmap-view` 只接收 `MediaMindmapProjectionV2` 转换出的内存树；不在产品中引入 Markdown parser、HTML renderer 或 toolbar。
5. SVG 文字按纯文本注入，禁止 `innerHTML` 接收模型内容。
6. 两个 adapter 都必须提供无 JS canvas/SVG 依赖的键盘语义替代视图。

## 3. 回退接口

```ts
interface TimelineRendererAdapter {
  mount(host: HTMLElement, projection: TimelineProjectionV2, actions: TimelineActions): void;
  setCursor(observedMs: number): void;
  fit(): void;
  destroy(): void;
}

interface MindmapRendererAdapter {
  mount(host: HTMLElement, projection: MediaMindmapProjectionV2, actions: MindmapActions): void;
  fit(): void;
  destroy(): void;
}
```

若 production bundle、CSP、Axe、键盘或 8 GiB/no-GPU 性能任一失败，替换为相同接口下自研 DOM/SVG adapter；不改 projection 合同，也不降低验收分母。

## 4. Spike 结论

组件能力能够支撑 wheel/drag/time scale 和 pan/zoom/collapse，但不能解决章节质量、证据闭合或问答质量。因此组件引入排在 `V3-5.1-1` 语义投影之后；禁止先替换 UI 再把固定窗口内容包装成“章节”。
