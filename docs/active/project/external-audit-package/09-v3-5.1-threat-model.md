# V3-5.1 Workspace 理解与交互威胁模型

日期：2026-10-10。状态：`DOCUMENT CANDIDATE`。

| ID | 威胁/假绿 | 强制控制 |
|---|---|---|
| W01 | 固定时间窗冒充语义章节 | 3..12 真实章节 + 边界特征记录 + 人工最小抽查 |
| W02 | LLM 创造证据或时间 | 输出只能引用 catalog ID；semantic closure；原始 evidence 不变 |
| W03 | 三视图各自生成导致漂移 | 单次 materializer、同 outlineId/content hash |
| W04 | frame 路径泄露/目录遍历 | ID allowlist endpoint、private cache、relative ref、no directory listing |
| W05 | 模型文本注入 HTML/SVG | React text/DOM textContent；sanitize；禁止 model innerHTML |
| W06 | timeline 编辑事实 | vis editable/add/update/remove 全禁；adapter 只发 seek intent |
| W07 | wheel 劫持整个 Workspace | 仅 hover/focus timeline 生效；边界释放；键盘/按钮替代 |
| W08 | listener/timer 泄漏 | wrapper destroy；route/task change cleanup；自动残留断言 |
| W09 | 播放游标控制错误视频 | 每次 read/seek 检查 source identity；变化立即停止 |
| W10 | 导图树循环或 orphan | root/parent/depth/cycle semantic verifier |
| W11 | visual 问题仅引字幕 | visual citation kind hard gate |
| W12 | 引用存在但不支持结论 | 12 问 citation support 复核 >=90%，critical error=0 |
| W13 | insufficient 被模型填满 | category/status/empty blocks 合同 |
| W14 | 旧 v2 task 被静默升级 | 明确“重新生成”；新版本 projection；不改封存数据 |
| W15 | selected-frame 授权被扩大到文本 | 独立 grounded-text scope；默认 disabled；撤销即停 |
| W16 | Cookie/key/raw media 外传 | outbound allowlist + hash；raw media upload count=0；secret scan |
| W17 | CDN/eval 破坏 Extension CSP | npm lock/integrity；0 remote scripts/eval；production bundle 扫描 |
| W18 | 第三方包供应链/许可漂移 | 锁版本、license inventory、bundle hash、升级重新审计 |
| W19 | 低资源机器因动画/DOM 卡死 | 8 GiB/no-GPU benchmark、DOM/heap/long-task 门槛；必要时 adapter 回退 |
| W20 | BiliNote/mock 结果混入真实验收 | fresh run provenance；production sample hash；fixtures 单独命名 |
| W21 | 人工验收替机器补证据 | A01..A20 先绿；人类只评体验 |
| W22 | 体验优化扩大成 V4 RAG/Agent | stage gate 和 API 禁止跨视频检索/知识写入/Agent |

风险接受：第三方 renderer 的可访问性需要实施期真实 Chrome 才能最终判定，因此组件采用保持可撤销；若失败，换 adapter 而非降低 A19/A20。
